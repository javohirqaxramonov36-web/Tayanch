Tayanch nimani to'plamaydi

  • Saytda ro'yxatdan o'tish, akkaunt va forma yo'q.
  • Hujjat (pasport, sertifikat) yoki insho yuklash imkoniyati yo'q.
  • Tayanch o'z analitika yoki reklama kodini ishlatmaydi.

Brauzeringizda saqlanadigan narsa

Ba'zi vositalar (masalan, tayyorgarlik rejasi) siz kiritgan narsani faqat sizning brauzeringizda saqlaydi. Bu ma'lumot hech qayerga yuborilmaydi va boshqa qurilmada ko'rinmaydi.

O'chirish uchun brauzer sozlamalarida shu sayt ma'lumotlarini tozalang.

Xosting

Sayt GitHub Pages'da joylashgan. Sahifa ochilganda so'rov GitHub serverlariga boradi.
