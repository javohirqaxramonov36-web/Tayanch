How XP works

XP for each action
ActionXP
Answer a practice question for the first time2 XP
Get it right on your first try (on top of the answer XP)+3 XP
Get a question right in review (once per question per day)4 XP
Answer the question of the day5 XP
Get the question of the day right+5 XP
  • Solving the same question again in a new session gives no new XP.
  • Practice answers sent in under 3 seconds give no XP.
  • You can earn up to 300 XP a day.
  • XP is counted on the server from your saved answers. It starts on the day the leaderboard opened: earlier answers do not count.
  • Weeks start on Monday and months on the 1st, at 00:00 Tashkent time.
  • Equal XP means an equal rank. XP is not a score prediction: it only counts practice.
