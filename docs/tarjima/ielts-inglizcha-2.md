## Ma'lumot fayllari
- `src/data/ieltsDarslar/ir-tfng.ts`, `ir-sarlavha.ts`: mavzu, xato izohlari, yechimlar inglizcha (parcha va savol matni avvaldan inglizcha).
- `src/data/ielts/writingSavollar.ts`: savol turi nomlari (Comparing, Solution to a problem, Giving and justifying an opinion, Advantages and disadvantages, Two-part question).
- `src/data/qavatlarAro.ts`: IELTS sahifasidagi SAT kartasi inglizcha; SAT sahifasidagi IELTS kartasidan "In Uzbek." olib tashlandi; Top Admission'dagi IELTS kartasiga "Ingliz tilida." qo'shildi.

## Namunalar
"Namuna" yorlig'i IELTS sahifalarida "Sample" (SAT kabi); "O'ylab topilgan vaziyat" → "Made-up situation".

## Asosiy misollar (oldin → keyin)
| Oldin | Keyin |
| --- | --- |
| Reading: javobni emas, dalilni qidir | Reading: look for the evidence, not the answer |
| False uchun matnda zid gap boʻlishi shart. Uni topa olmasang, javob Not Given. | False needs a sentence in the text that contradicts the statement. If you can't find one, the answer is Not Given. |
| Listening: eshitishdan oldin nimani kutishni bil | Listening: know what to expect before you hear it |
| Ortiqcha soʻz yozsang, javob toʻgʻri boʻlsa ham ball yoʻqoladi. | If you write extra words, you lose the mark even if the answer is right. |
| Writing Task 2: aniq fikr, aniq tuzilma | Writing Task 2: a clear idea, a clear structure |
| Bu band emas: rasmiy bandʼni faqat sertifikatlangan imtihonchi qoʻyadi. | This is not a band: only a certified examiner gives an official band. |
| Speaking: oʻzingni eshit | Speaking: listen to yourself |
| Ovozing hech qayerga yuborilmaydi va saqlanmaydi … | Your voice is not sent anywhere and is not saved … |
| True, False yoki Not Given: dalil gapdan boshlang | True, False or Not Given: start from the evidence sentence |
| Matching headings: paragraf nima haqida | Matching headings: what is the paragraph about? |
