# SAT grafik darsi: "Reset" tugmasi matni inglizchaga

Branch `sat-grafik-reset` (PR #35). Muallif tekshiradi. PR 2026-11-08 da, SAT matni inglizchaga o'tishidan oldin ochilgan edi. Main bilan birlashtirilganda (2026-11-17) faqat shu PR qo'shgan matn tarjima qilindi, sahifaning qolgan matni main'dagidek.

| Joy | Oldin | Keyin |
| --- | --- | --- |
| Tugma (`#grafik-qaytar`) | Boshlang'ich holat | Reset |
| Bosilganda animatsiya tugmasi (`#anim-boshla`) | Keyingi holat / Ko'rsatish | Next state / Show (rejim almashganda main'da ham shunday) |
| Bosilganda holat qatori (`#anim-holat`) | Tugmani bosing. | Press the button. (sahifa boshidagi matn bilan bir xil) |

Kod izohlari o'zbekcha qoldi.
